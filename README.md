# Atlas Route Studio

一个在浏览器中完成 PLY 点云浏览、Z 轴切片、二维导航点标注和有向路径配置的本地工具。

## 运行

```bash
npm install
./scripts/start.sh
```

默认访问地址为 `http://127.0.0.1:21990`。三个服务脚本分别是：

```bash
./scripts/status.sh
./scripts/start.sh
./scripts/stop.sh
```

也可以通过环境变量 `MAP_STUDIO_PORT` 或脚本的第一个参数覆盖端口，例如 `./scripts/start.sh 22000`。

## 使用流程

1. 点击“示例地图”加载 `maps/xian_map.ply`，或用“加载地图”选择本地 PLY 文件。3D 视图采用自由轨迹球控制，可跨越上下极点持续旋转；左上角可切换“旋转 / 平移”，右键拖拽也可随时平移。滚轮可持续深入放大查看局部细节，近距离时会自动调整裁剪面和点的屏幕尺寸。使用旁边的“− / + / 重置”可在 5%–100% 之间切换 3D 点云分辨率；点击“高程色”可按 Z 高度着色，并在窗口中显示以米为单位的高程比例尺，再次点击可恢复点云原始颜色。
2. 拖动 3D 视图右侧的单手柄 Z 高度条来移动截面中心；滑轨底端和顶端分别表示截面窗口贴合地图 Z 下界与上界，因此手柄可以完整走到两端，同时当前截面窗宽保持不变。二维地图会在后台重新投影，并采用原始世界坐标的 GPU 实时矢量投影；缩放时会重新绘制点位而不是拉伸固定图片，可持续放大检查精细位置。右下角的 `LIVE VECTOR` 表示该模式正在工作。
3. 切换到“添加导航点”，在二维地图上点击。点位保存 XYZ 和 RPY，Z 值来自点击位置附近的原始点云。
4. 切换到“连接路径”，依次点击起点和终点。路径有方向，创建后会自动打开速度/加速度配置。
5. 点击“检测”运行有向图强连通检查。可互相到达的路径显示绿色，未形成回路的路径显示黄色。
6. 用“导出 JSON”保存完整工程；“加载路径”可恢复导航点、路径参数和 Z 截面。

3D 和 2D 视图均显示世界坐标原点。2D 原点不在当前视野时会停靠在视图边缘，点击原点标记可快速定位到 `(0, 0)`。

3D 分辨率是非破坏性的均匀显示采样：降低档位只减少 GPU 当前绘制的点，2D 截面投影、导航点的原始 3D 坐标和导出数据仍使用完整点云。“重置”会恢复 100% 原始分辨率。

## 工作会话自动保护

页面会在本地 IndexedDB 中自动保护当前 PLY 地图、Z 截面、二维视图、三维高程配色模式、导航点、有向路径、运动约束及联通检测状态。同一次服务运行期间刷新页面会自动恢复；重新执行 `scripts/stop.sh` / `scripts/start.sh` 后，新服务会话会清理旧快照并从空白工程开始。底部状态栏的 `SESSION AUTO-SAVE` 表示自动保护正常。

导出的导航点同时包含通用的 `pose` 对象，以及兼容字段 `xzy`（`[x, z, y]`）和 `rpy`（`[roll, pitch, yaw]`）。
