# Atlas Route Studio

一个在浏览器中完成 PLY 点云 / 内嵌网格浏览、Z 轴切片、二维导航点标注和有向路径配置的本地工具。

## 运行

```bash
npm install
./scripts/start.sh
```

默认访问地址为 `http://127.0.0.1:21990`。三个服务脚本分别是：

```bash
./scripts/status.sh
./scripts/start.sh
./scripts/stop.sh
```

也可以通过环境变量 `MAP_STUDIO_PORT` 或脚本的第一个参数覆盖端口，例如 `./scripts/start.sh 22000`。

## 使用流程

1. 点击“示例地图”加载 `maps/xian_map.ply`，或用“加载地图”选择本地 PLY 文件。3D 视图采用自由轨迹球控制，可跨越上下极点持续旋转；左上角只保留一个“旋转”状态按钮，不再提供独立的“平移”按钮。按住 `Shift` 时，该按钮会即时切换为琥珀色的“Shift 平移”，图标、文字和底色同步变化，此时用左键拖拽即可临时平移；也可以在已经按住左键时再按 `Shift` 立即切换。该规则在机器人底盘控制、底盘平面拖拽和机械臂末端控制中同样生效，并优先于机器人对象拖拽。松开 `Shift` 后按钮和鼠标操作都会自动恢复旋转。拖拽过程中一旦鼠标越出 3D 画布，当前手势会立即取消，返回画布后需重新按下才会继续操作。机器人控制关闭时，键盘相机控制默认始终可用：点按或长按 `W/S` 前后移动、`A/D` 左右移动，运动始终限制在世界 XY 平面；`Q/E` 让相机与观察中心沿世界 Z 轴同步上升/下降，方向键 `←/→` 围绕观察中心执行 yaw，`↑/↓` 执行 pitch，所有操作均保持观察距离不变。`I/J/K/L` 不再占用，可用于浏览器或其他页面快捷操作。所有键盘移动与旋转按住 `Shift` 均可加速。编辑输入框时不会触发地图移动或旋转；在 3D 画布上滚轮缩放或按下鼠标会自动取回键盘焦点。右键拖拽可随时平移；一旦进入光学放大，或世界位移接近 GPU 浮点精度下限，`W/A/S/D/Q/E` 会统一切换为恒定屏幕速度的像素精密平移，避免按键停顿或需要长按数秒。“路径点”按钮可单独显示或隐藏 3D 导航点小球而不影响路径连线；小球几何体积为原设计的 20%，总览距离过远时会使用最小 8 px 的显示 LOD，避免埋没在密集点云中。滚轮采用“物理推近 + 光学细节缩放”的连续模型，在相机接近观察中心前自动切换为光学放大，避免最小距离和大坐标精度造成的缩放停止；近距离时也会同步调整裁剪面和点的屏幕尺寸。使用旁边的“− / + / 重置”可在 5%–100% 之间切换 3D 点云分辨率；颜色按钮默认显示高程色，之后按“原始色 → 纯白色 → 高程色”循环切换，3D 点云与 2D 矢量截面会同步着色；高程色模式会显示以米为单位的比例尺。
   如果 PLY 同时带有 `element face`，页面会自动采用“内嵌网格 + 独立点云”混合渲染：被 face 索引引用的区域显示为带深度明暗的实体三角面，未被任何 face 引用的顶点仍按点云显示，因此不会为了显示局部 mesh 而丢失其余扫描数据。网格与点云会同步切换高程色、原始色和纯白色；工具栏以 `PLY MESH / TRI` 标明实际面数，不再增加此前已经移除的结构面切换按钮。旁边的“网格质量”可选择自动、流畅、均衡、精细或全量，并始终以完整三角形为单位在全部 face 中均匀取样。

2. 点击顶部“加载机器人”，从 `robots/` 目录扫描出的列表中选择 URDF、GLB、GLTF 或 STL 机器人。URDF 会按原始 link/joint 树装配，并解析包内的 `package://` 网格；机器人基座默认放在地图原点，初始 XYZ 与 RPY 均为 0。当前 BOTX 模型会完整加载双臂末端的两台 Zivid 2 M70，并使用包内的 WebGL 高模替代 99 MB 原始 STL 传输。识别到该型号后，右侧栏底部会出现 M70 相机视图：可切换左/右末端、RGB 与按光学深度着色的 XYZ 点云；当 PLY 带有 face 时，RGB 会优先提取当前相机扩展视锥内的完整原色三角面，而不是从整幅地图均匀抽出一批零散面。RGB 点层只保留未被任何 face 引用的顶点并采用严格深度遮挡，因此只填补非网格区域，不会盖住已有 Mesh。相机底栏显示当前视锥实际提交的 `TRI` 数；若相机所在位置没有 Mesh，则明确显示 `POINT FALLBACK`。相机工具栏旁可直接调整与主 3D 同步的网格质量。滚轮或 `− / +` 支持 1–24 倍数字放大，放大后可拖动画面，双击或“重置”恢复；右上角按钮可打开全屏式大图。全屏大图左下角会以约 12 FPS 显示实时“主 3D 视角”缩略图，同步反映主视角、机器人姿态与环境关系；缩略图提供 `− / 倍率重置 / +` 和鼠标滚轮的 1–8 倍独立缩放，滚轮以指针位置为放大中心，双击画面恢复 1 倍，且不会改变主 3D 窗口或 Zivid 相机本身的视角。该预览复用既有 3D 画布的视频流，不会重复建立地图、机器人或碰撞场景，不支持画布流的浏览器则自动回退为低频画布镜像。该窗口按 URDF 中实时变化的 `zivid_left_optical_frame` / `zivid_right_optical_frame` 投影当前地图，采用 M70 的 1944×1200 原生规格、0.30–1.30 m 工作距离、700 mm 对焦距离以及约 56.6°×35.6° FOV；它明确标记为地图仿真视图，并不冒充尚未接入 Zivid SDK 的实时硬件流。为防止大型地图在打开“示教 / 相机”时重复占满显存，相机视图会为当前质量档建立紧凑的局部 Mesh LOD，并为 XYZ 点云保留最多 36 万点的独立降采样缓冲；机器人或末端连续运动时不会反复扫描全部 face，姿态稳定 280 ms 后才更新一次局部面。相机上下文异常也会被隔离并显示恢复提示，不会让主 3D/2D 工作区一起黑屏。加载完成后点击 3D 工具栏中的“机器人”，页面会推进视角并自动进入麦轮底盘控制，不再提供独立的“底盘控制”按钮；再次点击“机器人”可退出底盘控制并将键盘交还相机。控制开启后，`W/S` 沿机器人自身前向前进/后退，`A/D` 利用麦轮向左/向右横移，`←/→` 控制底盘 yaw 原地旋转；`Q/E` 仍用于相机世界 Z 轴升降，`↑/↓` 仍用于调整相机 pitch，`Shift` 既可加速键盘动作，也始终优先让左键拖拽平移视角。坐标采用 ROS 车体约定（局部 `+X` 前、局部 `+Y` 左、局部 `+Z` 上）。双击机器人底盘可进入平面拖拽模式，黄色圆环和十字标记会显示当前移动平面；随后在底盘上按住左键即可在地图 XY 平面自由移动，拖拽只改变 X/Y，当前 Z 与 roll/pitch/yaw 始终保持不变；按住 `Shift` 再拖拽时则平移视角，不会移动底盘。鼠标移出 3D 画布会立即结束当次拖拽，双击底盘或按 `Esc` 可退出该模式；如有地图坐标系末端锁定，拖动底盘时仍会持续执行全链 IK 补偿。双击任一机械臂的腕部或末端 Zivid 可进入对应左臂/右臂的末端控制模式，并自动解除底盘键盘控制；3D 窗口会在末端弹出随视角缩放保持约 58 px 的六自由度空间球，右侧浮层可在 `XYZ 位移` 与 `RPY 旋转` 间切换，也可直接输入世界坐标（米）与姿态（度）。系统依据 URDF 关节轴、层级和限位执行阻尼最小二乘逆解并驱动整条机械臂，面板会显示位置/姿态残差以及“IK 跟踪 / IK 受限”状态。完成拖拽后，卡片提供两种互斥锁定：“本体锁定”冻结机器人本体坐标系下的关节姿态，机器人移动时末端跟随本体；“全局锁定”保存地图坐标系下的末端绝对 XYZ/RPY，底盘移动后会持续驱动腰部、躯干和整条机械臂进行 IK 补偿，以便比较到达同一全局末端位姿时的全身关节姿势。另一末端已有锁定时，共享关节会自动避让以防两个约束相互争抢。卡片中的 `L / R · FREE / BODY / MAP` 状态条会持续提示两侧模式，再次点击当前锁定按钮即可解除并恢复空间球控制。
3. “加载机器人”右侧的“3D 鼠标”按钮使用 WebHID 检测 `3DConnexion SpaceMouse Wireless Bluetooth Edition`（`VID 0x256f / PID 0xc63a`），同时支持 Bluetooth LE、USB-C 直连及随附的 2.4 GHz 接收器。浏览器首次授权后会自动重新连接；首次使用会打开 14 项交互校准：前两项分别记录用于 XYZ 与 RPY 的左右实体键，后 12 项采集 `+X 前进 / −X 后退`、`+Y 向左 / −Y 向右`、`+Z 向上 / −Z 向下`、`+roll 左翻滚 / −roll 右翻滚`、`+pitch 前倾 / −pitch 后仰`、`+yaw 左偏航 / −yaw 右偏航`。每项动作会追踪外推动作高幅区间内完整的 `TX/TY/TZ/RX/RY/RZ` 六维向量，冻结峰值窗口并排除回程与松手回弹；成功后显示 0.5 秒确认并自动进入下一项，“返回上一步”可随时重录。标定结束后的实时信号面板会在绘制前合并真实设备同一帧内分开发送的 T/R 包，因此 TX～RZ 六项会同步显示且不受页面热更新影响。校准结果作为用户习惯配置保存在浏览器本地，同一设备在有线与无线间切换时复用；旧版配置会保留动作数据，但需补做新版实体键标定。运行时单击左键按 `X → Y → Z` 循环，单击右键按安全顺序 `YAW → PITCH → ROLL` 循环，空间球只会驱动当前明确选中的一个语义轴，因此传感器联动或噪声不会触发整体翻滚；双击同一实体键暂停，暂停后单击任意实体键恢复。推动空间球时，3D 窗口中央会以半透明文字显示当前轴及方向语义，静止 1 秒后渐隐。Zivid 相机大图的标题栏提供独立“SpaceMouse 视角”开关：开启后，当前选中的单轴输入会从主 3D 视角临时路由到左/右相机 optical frame，并通过现有 IK 连续更新整条机械臂；大图内会显示当前相机、控制轴和方向 HUD，关闭开关或退出大图后自动把输入交还主 3D 视角。SpaceMouse 输入期间采用合并截止时间的低开销保护，不再监听或拦截高频 `pointermove/mousemove`；页面仅捕获驱动额外映射出的按下、点击、右键菜单、滚轮和拖拽事件。点击已连接的“3D 鼠标”或完成校准进入场景时，会用该可信浏览器手势预激活 Pointer Lock；之后空间球一有物理输入即可临时把光标约束在网页内，低幅回弹结束 320 ms 后自动释放并恢复普通鼠标。RPY 模式另有 48 ms 的滚轮仲裁窗口，能够识别并拦截“系统滚轮先到、WebHID 报文后到”的 3DxWare 竞态；没有后续 SpaceMouse 报文时会把滚轮完整交还普通鼠标。若浏览器之外的系统光标在首次授权前仍受影响，需要在系统驱动中取消对应的普通鼠标映射。SpaceMouse 在主视角和 Zivid 相机大图中都不会修改相机距离或数字倍率，缩放始终只由普通鼠标滚轮完成；普通鼠标、键盘与机器人控制仍可并行使用。首次检测需由用户在 Chrome/Edge 的设备选择框中确认；Safari/Firefox 当前无法使用该入口。

4. 右侧“示教 / 相机”用于建立与导航图相互独立的层级化示教任务，数据结构为“任务 → 停车点 → 机械臂姿态”。点击“新建示教任务”后可先在弹窗中命名任务，并按需选择“添加当前位置为停车点”：选择后会按机器人当前地图位姿建立 `停车点 P01`，不选择则仅创建空任务，之后仍可点击“新增停车点”手动记录 MAP XYZ/RPY。底盘移动到下一处工位后再次点击“新增停车点”，即可记录新的停车位置，并用下拉框切换当前停车点。每个停车点下可连续记录 `A01 / A02 ...` 多组机械臂姿态，每组保存采集时的机器人基座 XYZ/RPY、URDF 全部可动关节以及左右 Zivid RGB/XYZ 快照。主工作台保留任务新建/打开、停车点新增/选择、记录当前机械臂姿态和归档统计；任务、停车点与姿态的重命名/删除、独立恢复及工程导出统一由同级“示教数据”页面管理。旧版平铺 `task.points` 工程在加载时会自动迁移到首个停车点，不会丢失历史姿态。Zivid 缩略图出现后，相机反算会自动启用，不再需要单独的“相机反算”模式按钮；画面左上方会显示 `OPTICAL IK · AUTO / 相机反算已激活`，任务或地图/机器人上下文不匹配时则明确显示等待状态。为了保持图谱控制台简洁，缩略图下方不再重复显示“相机位姿控制”；打开相机大图后，完整反算控制器固定在画面右侧，并与 Zivid 视图同步选择左臂或右臂 M70。控制器以相机 optical frame 为基准提供远近、上下、左右、旋转（yaw）、俯仰（pitch）和翻滚（roll）共 12 个方向按钮；位移步进使用 `5–10 cm` 滑块，旋转步进使用 `1–10°` 滑块，两者均按正整数间隔调节。每次点击都会通过阻尼最小二乘逆运动学反算整条机械臂关节值，3D 机器人、相机画面、当前地图坐标及求解残差同步更新。3D 工具栏中位于“机器人”与“重置视角”之间的“碰撞保护”是唯一保护开关，右侧卡片不再重复提供“自碰撞保护”状态或开关。该功能默认关闭；开启后系统会在专用 Web Worker 中建立环境点云及 Mesh 面采样的空间索引，并限频计算非底盘机器人视觉几何包络到环境的三维直线距离。发生干涉的部件使用红色常亮材质，无干涉但最近距离小于 100 mm 时改为黄色常亮，安全时恢复原材质；`base_link`、轮组、脚轮与麦克纳姆底盘命名的 link 不进入环境检测，避免地面噪声持续误报。关闭后 Worker、索引和警示材质会立即释放。“全关节控制”是非模态浮动窗口，进入“示教 / 相机”时保持关闭；需要调整时可手动点击图谱控制台标题栏的“关节”按钮显示或隐藏。窗口支持拖动、双击标题栏复位、右下角调整尺寸、最小化和关闭，并在控制台切页后继续保留。打开 Zivid 相机大图时关节浮窗会自动关闭以腾出观察空间；大图标题栏在“SpaceMouse 视角”左侧提供“关节调整”按钮，可按需重新弹出同一个关节控制窗口。窗口按底盘、躯干、头部和左右机械臂列出全部 URDF 可动关节，可用滑杆或精确数值一边观察 3D 机器人及相机画面一边实时调整，并提供全部归零。每个关节行末尾还有独立的 `IK LOCK` 按钮：锁定后，该关节会从末端空间球拖拽和相机反算的求解自由度中剔除，从而固定腰部或腿部角度、抑制全身过度后仰/前倾；锁定状态下仍可直接用该行滑块精调，工具栏可一次解除全部锁定。调整结果可命名保存为独立关节姿态，随后可直接执行、重命名或删除。
5. 拖动 3D 视图右侧的垂直“中心高度”条来上下移动 Z 截面区域，再使用控制器底部的“跨度”滑杆实时调整截面厚度。Z 控制域会在点云真实上下限两侧各外扩 5%（至少 0.05 m），轨道内的两条琥珀色刻线表示真实点云边界，因此截面可以略微越过地图顶面或底面。调整跨度时会尽量保持当前中心不变；接近扩展控制域的上下界时区域会自动贴边，且中心手柄仍可完整移动到滑轨两端。二维地图会在后台按当前高度范围重新投影，并采用原始世界坐标的 GPU 实时矢量投影；缩放时会重新绘制点位而不是拉伸固定图片，可持续放大检查精细位置。右下角的 `LIVE VECTOR` 表示该模式正在工作。顶部“重置视角”会同时恢复 3D 与 2D 的初始视角；两个窗口内也各有带文字的“重置视角”按钮，可只重置当前窗口而不改变另一个窗口。
6. 切换到“添加导航点”，在二维地图上点击。点位保存 XYZ 和 RPY，Z 值来自点击位置附近的原始点云。右侧“定位导航点”下拉框只列出当前地图已有点位；选中后，3D 与 2D 视图会用更近一级的特写同步平滑定位，选中点显示青色点体与紫蓝色呼吸环（即使此前隐藏了 3D 路径点也会自动恢复显示）。
7. 切换到“连接路径”，依次点击起点和终点。路径有方向，创建后会自动打开速度/加速度、正走/倒车及 3D 感知避障配置，并实时给出三维直线距离和排除高度误差的 XY 平面距离。之后在 2D 或 3D 窗口单击任意路径均可重新配置；在 3D 窗口单击导航点也会打开同一套右侧点位信息。点击右侧工程总览中的任意导航点或路径时，3D 与 2D 视图会同步平滑定位到对应对象，路径视图会自动包含两个端点。2D 工具栏提供独立“框选”模式，进入后在空白处按住左键可拉框多选导航点与路径；框住路径中段也能单独选中曲线路径，按 `Delete` 或 `Backspace` 可直接批量删除，删除导航点时会一并删除其关联路径。切回“选择 / 漫游”后左键拖拽仍用于平移。
8. 点击“检测”运行有向图强连通检查。可互相到达的路径显示绿色，未形成回路的路径显示黄色。
9. 点击顶栏“示教数据”进入独立数据页面，用管理卡片中的“导出工程”保存完整配置；导出文件以 `virtual-teaching-` 命名，机器人当前 XYZ/RPY 会写入 `robot.origin`，机械臂各关节位置会写入 `robot.joints`，命名保存的关节姿态写入 `virtualTeaching.jointPoses`。虚拟示教任务写入 `virtualTeaching.tasks[].parkingPoints[]`，停车点的绝对位姿位于 `mapPose`，其多组机械臂姿态位于 `poses[]`，每组包含 `mapPose`、`fullBodyJoints` 与 `cameraCapture`。`cameraCapture` 同步保存左右 Zivid 的 RGB 图像、深度预览和光学坐标系 XYZ+RGB 点云（XYZ 使用 `uint16-le/base64` 量化编码）。“加载路径”仍可恢复机器人选择、基座位姿、机械臂姿态、关节姿态库、分层示教任务及其双目视觉快照、导航点、路径参数和 Z 截面范围（包括中心与跨度）。

3D 和 2D 视图均以 ROS/RViz 风格显示世界坐标原点：X 为红色、Y 为绿色、Z 为蓝色，使用轴杆与箭头表达正方向。3D 坐标轴会根据当前光学缩放自动调整世界尺寸，将屏幕长度控制在约 68 px，避免近距离观察时遮挡点云细节。2D 原点不在当前视野时会停靠在视图边缘，点击原点标记可快速定位到 `(0, 0)`。

3D 与 2D 面板标题栏右侧分别提供“折叠 / 展开”按钮。折叠任一面板后，另一面板会自动占满地图工作区；系统最多只折叠一个面板，因此切换折叠目标时不会出现两个地图同时隐藏的情况。折叠状态会随当前工作会话自动保存并在刷新后恢复。

右侧图谱控制台采用三个独立子页：“路径 / 导航”集中显示连通性检测、导航点搜索、路径与点位列表及属性配置；“工程配置”单独显示地图、机器人、截面和当前定位摘要；“示教 / 相机”保留任务新建/打开、停车点新增/选择、当前机械臂姿态记录、归档统计，以及自动启用的相机反算和实时画面。已记录的数据在同级 `/teaching-data` 页面以“任务 → 停车点 → 机械臂姿态”的简约树状结构管理；左侧树支持逐级展开与折叠，右侧仅显示当前节点的属性、恢复、删除和双目快照操作。可通过顶栏“示教数据”或示教卡片中的“打开数据页”进入；返回主工作台后仍会保留当前任务与停车点上下文。全关节控制及姿态库保留在独立浮窗中，点击 2D 或 3D 中的导航点、路径时，控制台会自动切回“路径 / 导航”并打开对应属性。

3D 分辨率是非破坏性的均匀显示采样：源点数超过 100 万时，页面会自动选择“显示点数不超过 100 万”的最高现有档位，并在档位上标记“自动”；例如 268.5 万点会落到 25% 档。降低档位只减少 GPU 当前绘制的点，2D 截面投影、导航点的原始 3D 坐标和导出数据仍使用完整点云。自动选择后仍可用“− / +”手动覆盖，“重置”会恢复 100% 原始分辨率。

对于带内嵌网格的混合 PLY，点云分辨率档位只采样未成面点；网格质量独立控制三角面预算：流畅最多 18 万面、均衡最多 65 万面、精细最多 200 万面，全量则显示全部 face。自动档会让 150 万面以内的地图保持全量，超出后自动采用均衡档。主 3D 以该预算对全图取样；Zivid RGB 则先筛选当前扩展视锥，再在超出预算时降采样，保证近处局部面优先保持连续。

## 相机大图交互

相机大图采用相机优先布局：左侧为占据主要空间的 Zivid 画面，并始终按 M70 原生 `1944×1200`（1.62:1）比例完整显示；窗口比例不一致时使用留边适配，不拉伸、裁切或改变相机成像范围。右侧为辅助栏，上方放置相机位姿反算控制器，下方显示“主 3D 视角”。主 3D 窗格提供独立的“旋转 / 平移”模式：默认左键拖拽旋转，切换后左键拖拽平移，旋转模式下按住 `Shift` 可临时平移。操作会直接驱动既有主 3D 相机并立即同步辅助画面，用于从周围角度检查末端姿态，同时不会重复创建地图或机器人渲染场景。原有的 1–8 倍独立缩放仍然可用。

开启大图标题栏的“SpaceMouse 视角”后，当前 `XYZ/RPY` 分组与被控轴会直接显示在该开关按钮内；左上角不再放置固定的轴信息卡，减少对相机画面的遮挡。摇杆运动时，按钮内的轴标识会同步高亮。

相机大图中的“SpaceMouse 视角”同时也是连接入口：设备尚未连接时按钮仍可点击，并会在当前大图上直接启动既有 WebHID 授权与首次标定流程；已保存用户习惯时，授权完成后会自动切换到相机视角控制，无需关闭大图再操作顶部“3D 鼠标”。需要补做标定时，完成标定后也会自动接管当前相机。连接中和等待标定会直接显示在按钮内，避免把暂时等待误认为功能禁用。

当主 3D 工具栏的“碰撞保护”已开启时，Zivid RGB 与点云画面会同步读取同一检测结果。非底盘部件进入 10 cm 安全边界时，相机画面显示黄色边界与文字提示；检测到环境干涉时切换为红色边界，并显示命中的 link 和三维最近距离。提示在缩略图及相机大图中保持一致，保护关闭或恢复安全后自动消失。

## 工作会话自动保护

页面会在本地 IndexedDB 中自动保护已解析的点云坐标/颜色缓存，以及机器人选择、基座位姿、机械臂当前关节值、逐关节 IK 锁定集合、命名关节姿态库、虚拟示教任务与点位、Z 截面范围与跨度、二维中心与缩放、三维相机位置/旋转/缩放/精密平移偏移、点云配色、网格渲染质量、导航点、有向路径、运动约束、行驶策略及联通检测状态。视角另有一份轻量同步快照，用于覆盖“刚结束拖拽就立即刷新”时异步保存尚未完成的时间窗口。PLY 只在首次载入时解析，同一次服务运行期间刷新或稍后重新打开页面会直接恢复几何缓存、机器人模型、机器人基座、当前关节值、逐关节 IK 锁定、关节姿态库、示教记录和两个窗口的上次视角；为避免误操作与默认占用大量计算资源，机器人键盘控制开关、碰撞保护开关、机械臂末端控制模式及临时的末端锁定状态在刷新后均恢复为关闭，但已求解并锁住过的最终关节姿态仍会保留。重新执行 `scripts/stop.sh` / `scripts/start.sh` 后，新服务会话会清理旧快照并从空白工程开始。底部状态栏的 `SESSION AUTO-SAVE` 表示自动保护正常。

带 mesh 的 PLY 会额外缓存原始三角面索引；首次以新版本重新选择一次文件后，后续刷新可直接恢复混合渲染，不会再次解析数百万个 face。

导出的导航点同时包含通用的 `pose` 对象，以及兼容字段 `xzy`（`[x, z, y]`）和 `rpy`（`[roll, pitch, yaw]`）。
