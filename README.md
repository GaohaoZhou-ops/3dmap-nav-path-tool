# Atlas Route Studio

一个在浏览器中完成 PLY 点云浏览、Z 轴切片、二维导航点标注和有向路径配置的本地工具。

## 运行

```bash
npm install
./scripts/start.sh
```

默认访问地址为 `http://127.0.0.1:21990`。三个服务脚本分别是：

```bash
./scripts/status.sh
./scripts/start.sh
./scripts/stop.sh
```

也可以通过环境变量 `MAP_STUDIO_PORT` 或脚本的第一个参数覆盖端口，例如 `./scripts/start.sh 22000`。

## 使用流程

1. 点击“示例地图”加载 `maps/xian_map.ply`，或用“加载地图”选择本地 PLY 文件。3D 视图采用自由轨迹球控制，可跨越上下极点持续旋转；左上角只需选择鼠标左键的“旋转 / 平移”行为，在旋转状态按住 `Shift` 再用左键拖拽可临时平移，也可以在已经按住左键时再按 `Shift` 立即切换。临时平移启用时，“平移”按钮会变为琥珀色的“Shift 平移”，松开后仍保持原来的旋转模式。拖拽过程中一旦鼠标越出 3D 画布，当前手势会立即取消，返回画布后需重新按下才会继续操作。键盘控制默认始终可用，无需切换模式：点按或长按 `W/S` 前后移动、`A/D` 左右移动，运动始终限制在世界 XY 平面并保持当前 Z 高度；方向键 `↑/↓` 让相机与观察中心沿世界 Z 轴同步升高/降低；`J/L` 向左/向右转，`I/K` 向上仰/向下俯，键盘转向会围绕当前观察中心连续旋转并保持观察距离；按住 `Shift` 可加速。编辑输入框时不会触发地图移动或旋转。右键拖拽可随时平移，高倍光学放大时会自动使用精度不受世界坐标浮点误差影响的像素平移。“路径点”按钮可单独显示或隐藏 3D 导航点小球而不影响路径连线；小球几何体积为原设计的 20%，总览距离过远时会使用最小 8 px 的显示 LOD，避免埋没在密集点云中。滚轮采用“物理推近 + 光学细节缩放”的连续模型，在相机接近观察中心前自动切换为光学放大，避免最小距离和大坐标精度造成的缩放停止；近距离时也会同步调整裁剪面和点的屏幕尺寸。使用旁边的“− / + / 重置”可在 5%–100% 之间切换 3D 点云分辨率；颜色按钮默认显示高程色，之后按“原始色 → 纯白色 → 高程色”循环切换，2D 矢量截面会同步着色；高程色模式会显示以米为单位的比例尺。
2. 拖动 3D 视图右侧的单手柄 Z 高度条来移动截面中心；滑轨底端和顶端分别表示截面窗口贴合地图 Z 下界与上界，因此手柄可以完整走到两端，同时当前截面窗宽保持不变。二维地图会在后台重新投影，并采用原始世界坐标的 GPU 实时矢量投影；缩放时会重新绘制点位而不是拉伸固定图片，可持续放大检查精细位置。右下角的 `LIVE VECTOR` 表示该模式正在工作。顶部“重置视角”会同时恢复 3D 与 2D 的初始视角；两个窗口内也各有带文字的“重置视角”按钮，可只重置当前窗口而不改变另一个窗口。
3. 切换到“添加导航点”，在二维地图上点击。点位保存 XYZ 和 RPY，Z 值来自点击位置附近的原始点云。右侧“定位导航点”下拉框只列出当前地图已有点位；选中后，3D 与 2D 视图会用更近一级的特写同步平滑定位，选中点显示青色点体与紫蓝色呼吸环（即使此前隐藏了 3D 路径点也会自动恢复显示）。
4. 切换到“连接路径”，依次点击起点和终点。路径有方向，创建后会自动打开速度/加速度、正走/倒车及 3D 感知避障配置，并实时给出三维直线距离和排除高度误差的 XY 平面距离。之后在 2D 或 3D 窗口单击任意路径均可重新配置；在 3D 窗口单击导航点也会打开同一套右侧点位信息。点击右侧工程总览中的任意导航点或路径时，3D 与 2D 视图会同步平滑定位到对应对象，路径视图会自动包含两个端点。2D 工具栏提供独立“框选”模式，进入后在空白处按住左键可拉框多选导航点与路径；框住路径中段也能单独选中曲线路径，按 `Delete` 或 `Backspace` 可直接批量删除，删除导航点时会一并删除其关联路径。切回“选择 / 漫游”后左键拖拽仍用于平移。
5. 点击“检测”运行有向图强连通检查。可互相到达的路径显示绿色，未形成回路的路径显示黄色。
6. 用“导出 JSON”保存完整工程；“加载路径”可恢复导航点、路径参数和 Z 截面。

3D 和 2D 视图均以 ROS/RViz 风格显示世界坐标原点：X 为红色、Y 为绿色、Z 为蓝色，使用轴杆与箭头表达正方向。3D 坐标轴会根据当前光学缩放自动调整世界尺寸，将屏幕长度控制在约 68 px，避免近距离观察时遮挡点云细节。2D 原点不在当前视野时会停靠在视图边缘，点击原点标记可快速定位到 `(0, 0)`。

3D 与 2D 面板标题栏右侧分别提供“折叠 / 展开”按钮。折叠任一面板后，另一面板会自动占满地图工作区；系统最多只折叠一个面板，因此切换折叠目标时不会出现两个地图同时隐藏的情况。折叠状态会随当前工作会话自动保存并在刷新后恢复。

3D 分辨率是非破坏性的均匀显示采样：源点数超过 100 万时，页面会自动选择“显示点数不超过 100 万”的最高现有档位，并在档位上标记“自动”；例如 268.5 万点会落到 25% 档。降低档位只减少 GPU 当前绘制的点，2D 截面投影、导航点的原始 3D 坐标和导出数据仍使用完整点云。自动选择后仍可用“− / +”手动覆盖，“重置”会恢复 100% 原始分辨率。

## 工作会话自动保护

页面会在本地 IndexedDB 中自动保护已解析的点云坐标/颜色缓存，以及 Z 截面、二维中心与缩放、三维相机位置/旋转/缩放/精密平移偏移、点云配色模式、导航点、有向路径、运动约束、行驶策略及联通检测状态。视角另有一份轻量同步快照，用于覆盖“刚结束拖拽就立即刷新”时异步保存尚未完成的时间窗口。PLY 只在首次载入时解析，同一次服务运行期间刷新或稍后重新打开页面会直接恢复几何缓存和两个窗口的上次视角；重新执行 `scripts/stop.sh` / `scripts/start.sh` 后，新服务会话会清理旧快照并从空白工程开始。底部状态栏的 `SESSION AUTO-SAVE` 表示自动保护正常。

导出的导航点同时包含通用的 `pose` 对象，以及兼容字段 `xzy`（`[x, z, y]`）和 `rpy`（`[roll, pitch, yaw]`）。
